**Document Version:** 2.0  
**Engine Compliance:** UPCE-MASTER-1.0 (§56, §69), UPCE-ADDENDUM-2.0, doc2.md  
**Status:** Approved Integration Standard  

---

## 1. Overview & Architectural Role

The **Scene Graph Intermediate Representation (IR)** is the deterministic integration contract between the **CAD Agent v2** and downstream rendering / editing surfaces:
- The **2D Canvas** (`drawingReducer.ts` and React canvas)
- Downstream **AutoCAD DXF Exporters**
- Downstream **3D IFC / BIM Extruders** (BIMvision, OpenCASCADE)
- **BoQ & Rate Analysis Engines** (Standard Data Book, SoR)
- **Official Government PDF Exporters** (PWD / IRC:SP:13)

### Core Invariants Enforced in the IR
1. **Zero Conformal Scaling (§8, §29.4, §81):** Geometry is never proportionally scaled ($k = L_1/L_0$). Undriven dimensions (wall thickness, slab thickness, haunches, cushion) remain strictly invariant across parameter updates.
2. **Planar Rigid-Body Anchor Rule (§18):** 3 degrees of freedom (2 translation + 1 rotation) are explicitly anchored ($d_{\text{anchor}} = 0$) preventing rotational or translational drift in variational solves.
3. **Model-Space Millimeters (§17, §84):** All geometric dimensions and tolerances are defined in absolute millimeters (`mm`), never in screen pixels or viewport units.
4. **Symbolic Parametric Preservation:** Every geometric primitive preserves its symbolic parametric expression (e.g. `depth = span / 12`, `outer_w = span + 2 * wall_thk`) alongside evaluated numeric coordinates.

## 3. Node Type Specifications

| Node Type | Required Attributes | Evaluated Coordinate Fields |
|---|---|---|
| `line` | `id, layer, symbolic.x1, y1, x2, y2` | `x1, y1, x2, y2` (mm) |
| `rectangle` | `id, layer, symbolic.x, y, width, height` | `x, y, width, height` (mm) |
| `circle` | `id, layer, symbolic.cx, cy, r` | `cx, cy, r` (mm) |
| `arc` | `id, layer, symbolic.cx, cy, radius, startAngle, endAngle` | `cx, cy, radius, startAngle, endAngle` |
| `polyline` | `id, layer, points: Array<{x, y}>` | Evaluated vertex array (mm) |
| `text` | `id, layer, symbolic.x, y, text` | `x, y, height, rotation` |
| `dimension` | `id, layer, type, entityA, [entityB]` | `value` (mm) + formatted label text |

## 5. Downstream Ingestion Contract

- **TypeScript Canvas:** Loaded directly via `drawingReducer(state, { type: "LOAD_SHAPES", shapes: output.shapes })`.
- **AutoCAD / Civil 3D:** Ingested via `output.dxf` (R2010 AC1024 format).
- **FastAPI / Python Solver:** Ingested via JSON Scene Graph IR.
