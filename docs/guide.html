Orientation

Before you start

Two ideas make everything else predictable. Neither takes long.

Three personas, one drawing
Top right of the ribbon: Draft to put geometry on the sheet, Author to say what it means, and Run to use a published template the way a project engineer would. Same drawing throughout — the persona changes which panel you get, not what exists.
Every edit goes round the same loop
You change intent — a value, a rule, a count — and the solver answers. If it can honour everything you have declared, the geometry moves. If it cannot, nothing changes and you are told which requirements disagree. There is no half-applied state to clean up.
Dragging runs the loop backwards
The canvas writes your drag straight into the drawing, then the model catches up about a tenth of a second after you stop. So a pinned shape springs back, and a grouped unit follows the piece you pulled. That pause is deliberate: one solve per gesture, not one per frame.
Read this

Nothing in this system is a shape. There is no culvert, no wall, no cell. There are lines, closed boundaries, named values and rules between them. Every exercise below works the same on a box culvert, a retaining wall, or a triangle you drew this morning — and that is the reason the same nine controls cover all of it.

Level 1 · Basics

The loop

Draw something ordinary, then teach the system what it is. Six exercises; about ten minutes.

Analyse a drawing

Start with two rectangles. Anything will do — the point is to see what the system reads.

  1. In Draft, draw two rectangles roughly 400 × 300, a gap apart.
  2. Switch the persona to Author.
  3. Press Step 1 ▸ Analyse geometry.

Nothing moves. The drawing is measured, relationships are proposed, and the remaining freedom is worked out from the constraint system itself.

What is still free

status Under-defined — 16 independent movements remain reads · Rectangle 1 can slide across the sheet · Rectangle 2 can slide across the sheet
Why

Sixteen is not a complaint. Eight corners × two coordinates, minus what the rectangles' own right angles already hold. A drawing with freedom left is a drawing that can still be driven; the job of the next few steps is to spend that freedom on purpose.

Accept what the drawing already shows

Step 2 ▸ Relationships found lists what the detectors measured — parallel edges, equal lengths, aligned corners. Each card shows the evidence and what accepting it will keep true from then on.

  1. Read a card. It names what was measured and how far off exact it currently is.
  2. Accept if you meant it. Not intended if the drawing just happens to look that way.
  3. Or take the lot with Accept all (n) in the section header.
Note

Only admissible cards offer buttons. A relationship already implied by the rules in force is shown but cannot be accepted — adding it would be a second answer to a settled question, and the degrees-of-freedom report would rightly call it redundant.

When the list empties you will see “Every relationship the detectors can see is either already in the model or already implied.” That is the cue to move to Step 3.

Answer a design question

Step 3 ▸ Decide the design is where the system stops guessing. Where more than one answer is valid it asks, and each option carries the freedom it would remove — measured by applying it to a copy and re-checking, not estimated.

  1. Read the question and the movement it names underneath.
  2. Pick the option that matches your intent. A value is created and named for you.
  3. Obvious repairs appear as Apply all fixes (n) — safe to take in one go.
Blocked

A question shown in a dashed box with no options is waiting on something else — usually an anchor. The text says what. Answer that first and the question opens up.

Anchor the drawing

Until one point is pinned, the whole drawing can slide and the solver has no reason to prefer one position over another. Accept the anchor question when it appears, or pin a corner yourself.

  1. Take the “hold this corner in place” option in Step 3 when offered.
  2. Drag that corner on the canvas and let go.
  3. It returns to exactly where it was pinned. The panel says which rule held it.

After the drag settles

notice Rectangle 1 could not stay where it was put — a rule holds it. corner 100.000000, 100.000000

Type a value on the sheet

Named values appear as badges on the drawing itself, not only in the panel. They are live controls.

  1. Single click a badge to edit it.
  2. Type the new figure. Enter commits, Esc cancels.
  3. The geometry re-solves, or the edit is refused with a reason and nothing moves.

The same values are listed in Step 4 ▸ Values, each with a role tag: DRIving (you set it), DERived (a formula sets it), FIXed, MEAsured (it only reports). Double-click a name there to rename it.

Read and manage the rules in force

Rules in force is the whole design intent in one list. Click a row to expand it and read who created it and why.

  • The power icon switches a rule off temporarily — the fastest way to find out whether it is the one fighting you.
  • The cross removes it for good.
  • A rule marked fact cannot be removed. It is part of what the shape is — a rectangle's own right angles. Explode the shape into lines if you need those corners free.
Habit

When an edit is refused, come here first. Suppress the rule named in the message, redo the edit, and decide afterwards whether to delete the rule or restore it.

Level 2 · Intermediate

Relationships you assert

The detectors only find what the drawing shows. Everything else is a design decision, and these are the tools for stating one.

Name a measurement

Step 4b ▸ Relationships you assert turns any measurable distance into a named value.

  1. Select the geometry on the canvas.
  2. Pick what to measure from the list that appears.
  3. Give it a name — WallThickness, ClearSpan, whatever your office calls it.

Name it as measured and it only reports. Name it as driving and typing into it moves the drawing.

Take a derived value under control

A badge showing a value that follows something else is derived. Hovering gives you a help cursor.

  1. Double-click the derived badge.
  2. It becomes driving, and you can now type into it.
By design

Single click is deliberately not this. A derived value being derived is usually the point — it is following something on purpose — so taking it under manual control has to be a decision, not a slip of the mouse.

Write a formula

Two ways, depending on whether the relationship already exists in the geometry.

  1. Let it be found: Step 4 ▸ Find derived values. Each proposal is validated by perturbing its inputs and re-checking that the formula still predicts the result. The card shows how many test cases passed.
  2. Write it yourself: in Step 4b, enter an expression such as OtherWidth - 2 * WallThickness. Dependencies are read from the parsed expression, so renaming an input updates everything that reads it.

Hold one edge against another

Step 4c ▸ Relate two things, top panel: Hold one edge relative to another. This is the tool for “when I move this line, that line comes with it”.

  1. Select both shapes on the canvas.
  2. Choose a reference edge, then the edge that follows it.
  3. Pick one of the three ways to hold them. Each shows what it measures right now.
  4. Hold this relationship.
OptionHoldsReach for it when
AcrossHorizontal separation of the two edges' midpointsThings line up on a grid, whatever their angle
Up the sheetVertical separation, same ideaLevels, soffits, courses
Square to itPerpendicular offset, signed — which side mattersA thickness that must survive the edge rotating

Drive the first edge; the second follows

before R1 x=0 w=400 R2 x=500 after R1 x=0 w=700 R2 x=800 gap 100.0 held
Why

Because every option is created at what it currently measures, agreeing to one moves nothing. You are recording the arrangement you already drew, then driving it afterwards.

Drive the gap between two centres

Same section, bottom panel. Closing the distance brings the shapes together without either of them changing size.

  1. Select two closed shapes.
  2. Name the centre-to-centre distance.
  3. Type smaller numbers into the value it creates.

Driving the named gap down

gap 900 R1 x=0 w=400 R2 x=900 w=400 gap 700 R1 x=0 w=400 R2 x=700 w=400 gap 500 R1 x=0 w=400 R2 x=500 w=400

Works on rectangles, circles and anything drawn from loose lines: the centre comes from the boundary, not from the shape's type.

Watch for

If the shapes have nothing holding their own size, closing the centres can squash one instead of moving it — both answers satisfy the rule, and the solver takes the cheaper one. Name the sizes first and the notebook picture is the only solution left.

Level 3 · Advanced New

Units that move as one

Grouping used to be a label. Now it can be a body: three freedoms — across, up, and turn — and nothing inside it can change shape.

Make a unit

  1. Select the geometry that makes up one unit. Canvas, or Choose shapes from list.
  2. Type a name in Step 5 ▸ Reuse and repeat.
  3. Make unit.

The card that appears reports what the unit measures along the array direction, which you will need in Level 4:

Unit · 2 shape(s) 360.0 across · opening 300.0 · wall 30.0

Make it move as one piece

  1. Tick Moves as one piece on the unit's card.
  2. Watch the freedom count in What is still free.

A triangle drawn from three loose lines

loose 10 coordinates can move rigid 3 — across, up, and turn
Why it works

The unit is no longer described by its corners but by a frame. There is no vector in what the solver can search that moves one corner relative to another, so internal lengths and angles hold exactly — not to a tolerance, but because distortion has become inexpressible.

Drag one line and take the whole unit

  1. Drag one line of a rigid unit across the sheet.
  2. Wait a moment for the model to catch up.

Dragging one edge of three by +120, +40

before T1 (0.0,0.0)-(500.0,0.0) T2 (500.0,0.0)-(250.0,400.0) after T1 (120.0,40.0)-(620.0,40.0) T2 (620.0,40.0)-(370.0,440.0)

Every member moved by exactly the amount you dragged. Turn a line instead and the unit turns with it — side lengths unchanged to six decimals.

Compare

Untick the box and repeat the drag. The line you grabbed goes; the rest stays where it was. That is what a group is without this — a name.

Tether a unit to a datum

The two halves together: a rule pulls the body, and the body arrives whole.

  1. Draw a datum line clear of the unit. Pin both its ends.
  2. In Step 4c, hold one edge of the unit against the datum.
  3. Drive that distance.

The unit slides to suit. Every internal length and angle survives, because the solver was never able to change them.

Understand what rigid does not do

  • It does not pin the unit. Rules still move it. If you want it held, pin it or dimension it.
  • It resists turning, but does not forbid it. One dimension on a free body leaves the rotation open, and the unit slides rather than spins — the residual tilt is under a micron across a half-metre section. Give it a rule that can only be met by turning and it turns: a bar pinned at one end with its far end driven 50 up settles at exactly 30°, still 100 long.
  • Two units cannot share a corner. Ticking the box on the second is refused, in a sentence, naming how many corners overlap. Two pieces that move independently cannot both decide where the same corner is.
Level 4 · Advanced New

Repeats and pitch

A count changes how many pieces exist, so it is never something the solver solves. The drawing is rebuilt from the rule, then handed over.

Choose a spacing mode

Three radio buttons on the unit's card, and the choice matters more than the number.

ModeYou holdCorrect when
Material between copies The gap. Pitch is measured off the unit, every rebuild. The thing between copies is structure — a web, a joint, a nib. Start here.
Pitch fixed A literal centre-to-centre figure. The run grows with the count. The pitch is the specification — bolt centres, post spacing.
Overall run fixed The total length. Pitch closes up as the count rises. You must fill a known opening with however many it takes.
The difference

A pitch typed as a number is right until the unit changes size, and then every copy is in the wrong place. In gap mode the pitch is not stored at all — it is the unit's own opening plus the gap, re-measured on every rebuild. That is the whole of it.

Array a hollow unit

Draw an outline 360 × 260 with an opening 300 × 200 inside it — a 30 wall all round.

  1. Select both, Make unit.
  2. Leave the mode on hold the material between copies.
  3. Set the count to 3. Leave the web box alone.
  4. Repeat it.

The panel, before you press it

Pitch will be 300.0 + 30.0 = 330.0 mm, re-measured whenever the unit changes. Starts at 30.0, which is what already sits between this unit's opening and its outside.

The result

webs 30.0 30.0 cells x=30 w=300 x=360 w=300 x=690 w=300
Where 30 came from

Nothing was told what a wall is. The opening is the largest hole in the largest closed thing the unit owns; the wall is what is left either side of it. Same measurement on a hollow pier, a ring beam, or a shape nobody has a name for.

Change the material between copies

  1. Find the value named UnitGap in Step 4 ▸ Values.
  2. Type 55.

Webs, and the cells that did not move to make room

webs 55.0 55.0 cells 360 wide, opening 300 — unchanged pitch 355.0

It is a real named value like any other: rename it, publish it, or drive it from a formula so the web follows the wall thickness automatically.

Widen the unit and watch the pitch follow

The exercise that shows why the mode matters.

  1. Widen the unit's outline to 460 and its opening to 400 — the wall stays 30.
  2. Let the model settle.

Nothing was retyped

opening 300.0 → 400.0 pitch 355.0 → 455.0 re-measured webs 55.0 55.0 held

The panel shows its working: 3 x · pitch 455.0 = 400.0 + 55.0, measured. Do the same in pitch fixed mode and the copies march straight through each other — which is exactly the right behaviour for that mode, and the wrong mode for this drawing.

Array something solid

A unit with no opening has nothing to measure a web against, so the gap is measured outside to outside. The panel says so and the label changes from web to gap.

500.0 across · solid This unit encloses nothing, so the gap is measured outside to outside: pitch 500.0 + 0.0 = 500.0 mm.

Type the clear spacing you want — 1880 for a post at 2000 centres on a 120 post.

Change the count

Once a repeat exists, the card stops offering a count box and points you at Step 4 ▸ Values. The count lives there as an integer.

Why there

Because it is topology, not geometry. Changing it does not stretch anything — it rebuilds the drawing with a different number of pieces and hands the result to the solver. A count of 6 followed by a count of 2 leaves exactly two.

Level 5 · Advanced New

Solids that meet

Two pours running into each other has two honest answers, and which one applies is your call, not the solver's.

Drive two units together

  1. Place two closed units a little apart.
  2. Move one until it crosses into the other.

A new section appears: Step 5b ▸ Solids that meet.

Left cell and Right cell have run into each other by 19.0 mm.
Not an error

The edit is never refused and your shapes are never rewritten. Overlapping is how you draw a monolithic structure in the first place; refusing it would make the drawing impossible.

Choose one pour, or a joint

  1. Leave Read them as one pour ticked for monolithic construction.
  2. Untick it for an expansion joint between two separate pours.
SettingPoursAreaWeb
One pour1Shared material counted onceReported — 30 + 30 − 20 = 40.0
Joint2Each measured in fullNone; the seam stays

One pour, two hollow units overlapping by 20

Pours 1 Voids kept 2 Shared material 0.0052 m² Counted once 0.0620 m² Web after merge 40.0 mm

Both voids survive the merge — they were never touched by it. That is the point of doing this through a planar map rather than a clipping library.

Take it back

Drag the two apart. The section disappears and the solids are two again.

Guaranteed

The merge is derived — it never writes back over what you drew. Your shapes stay the parametric source, which is the only reason the overlap is recoverable. Nothing here consumes the parameters that produced it.

Level 6 · Handover

Publish and run

Turning a drawing into something a colleague can use without opening it.

Check it

  1. Name the template in Step 6 ▸ Publish.
  2. Press Check it.

Each check passes, warns or fails with a reason. The sweep at the bottom is the one worth reading: it re-solves the drawing at a spread of test values and reports how many came back with every declared relationship intact.

sweep 12 of 12 test values re-solved with every declared relationship intact.

Publish deliberately under-constrained work

A drawing that is meant to keep some freedom is publishable. Tick the intentional-freedom option rather than inventing rules to silence the check — inventing them is how a template ends up fully constrained and wrong.

Use it as a project engineer

  1. Switch the persona to Run.
  2. Type into the published values, grouped as you grouped them.
  3. Read Worked out for you for the derived figures.

What this drawing keeps true lists the invariants, re-measured on the solved geometry — not assumed from the fact that the solver returned.

Step back

Step 1 ▸ Step back undoes one design decision. It is separate from the drafting undo: geometry and intent have their own histories, and stepping back a decision does not unpick the lines you drew.

Putting it together

A three-cell box, start to finish

Every control above, in the order you would actually use them.

  1. Draft. One cell only: outline 360 × 260, opening 300 × 200. Never draw the other two.
  2. Author ▸ Step 1. Analyse. Read the freedom.
  3. Step 2. Accept the alignments you meant. Reject the coincidences.
  4. Step 3. Answer the anchor question first — it unblocks the rest.
  5. Step 4b. Name ClearSpan and WallThickness.
  6. Step 4c. Hold the opening square to the outline so the wall survives any rotation.
  7. Step 5. Select both shapes, Make unit, name it Cell.
  8. Step 5. Tick Moves as one piece so the cell cannot be distorted by anything downstream.
  9. Step 5. Mode: material between copies. Count 3. Leave the web at its measured default. Repeat it.
  10. Step 4. Drive ClearSpan. Watch the pitch follow and the webs hold.
  11. Step 5b. If you close the cells right up, decide monolithic or jointed.
  12. Step 6. Check it, then publish.
The test

Change ClearSpan from 300 to 400 and look at the webs. If they still read 55.0 / 55.0 the drawing is parametric. If they moved, you are in pitch mode.

Reference

What not to click

Don't

Accept a detected relationship you did not mean. “Not intended” is a real answer and costs nothing. An accepted coincidence becomes a rule that fights every later edit.

Don't

Draw the copies. Draw one unit and array it. Three hand-drawn cells are three unrelated things, and no count will ever govern them.

Don't

Type a pitch into the gap box. In gap mode that field is the material between copies. Entering 330 there gives a 330 web, not a 330 pitch.

Don't

Put one shape in two rigid units. It is refused, and the refusal is right: two bodies that move independently cannot both decide where a shared corner is.

Don't

Single-click a derived badge expecting to edit it. Double-click converts it. Single click on a derived badge is intentionally inert.

Don't

Delete a rule to make a refusal go away. Switch it off, redo the edit, and then decide. The power icon is reversible; the cross is not.

Known limits

What this build does not yet do, stated plainly so you do not go looking.

  • Arcs are not constrainable. The arc type exists but is not part of the shape set the authoring kernel lowers, so an arc will not follow a rigid unit and cannot carry a rule. Lines, rectangles, circles, ellipses, polygons and stars all work.
  • No tangent constraint. Nothing creates one yet.
  • Angles can be solved but not authored. The solver handles an angle rule; no control creates one.
  • Live drag does not resist under the cursor. The rules answer when you let go, about a tenth of a second later, rather than fighting the pointer in real time.
  • Multi-view, IFC, bill of quantities and PDF sheets are downstream. This is the authoring environment; a published template is what the production engine consumes.
