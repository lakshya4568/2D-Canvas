TYPE LEGEND
-----------
I    = Input (user-editable design variable)
C    = Computed (derived by formula)
S    = Static / Engineering constant
A    = API-fetched (from RDSO standard lookup)
RDSO = Looked up from RDSO standard design table by span length
func = Helper coordinate transform function
