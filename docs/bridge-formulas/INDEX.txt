DOCUMENT SET PURPOSE
--------------------
This documentation set captures every engineering formula used in the
Aagento Bridge CAD platform for building, sizing, validating, and drawing
railway and highway bridge structures. It is structured for use as training
data for fine-tuning a language model (LoRA) on civil/structural engineering
formulas, design codes, and computational drafting logic.

--------------------
